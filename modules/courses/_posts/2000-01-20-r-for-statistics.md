## Using R and Rstudio for Statistical Analysis

-   **Presenter:** George Savva (QIB)
-   **Available to:** All NBI-based (QIB, TSL, EI, JIC) staff and students
-   **Priority for students:** Highly Recommended
-   **Dates/Venue:** 14, 15, 16 Jan 2026, repeated on 27, 28, 29 April 2026.  Chris Lamb lecture theatre, JIC.

## Learning objectives

-  Load, manipulate, clean and code datasets
-  Conduct, diagnose and report common statistical analyses
-  Know the basics of the R language for statistical computing
-  Understand how R represents datasets
-  Make high quality graphs using ggplot2
-  Resources for self-directed future learning
